# صور معرض لوحتي

ضعي هنا صور لوحات الطلاب (jpg / jpeg / png / webp).

- **اسم الملف = اسم الفنان/ة** الذي يظهر تحت اللوحة. مثال: `ليان.jpg`.
- لعدّة لوحات لنفس الطالب/ة أضيفي رقماً: `ليان 2.jpg`، `ليان 3.jpg` (الرقم لا يظهر).
- ملف بدون اسم واضح (مثل `IMG_1234.jpg`) يظهر بلا اسم.
- الترتيب: الأحدث إضافة إلى المستودع يظهر أولاً.

بعد رفع الصور، اطلبي من Claude تحديث صفحة المعرض.
